How it works

The machine knows the comparisons.

Each sentence arrives with its assigned place in a set of 54 possibilities. The console finds valid two-sentence pairs where exactly one part changes. The choices are written in everyday words; the machinery stays out of sight.

For the one-sentence game, alternatives come from nearby possibilities. In this first edition, every cartridge assignment is treated as the answer key supplied by its creator.
